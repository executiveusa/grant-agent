# Gauntlet Bars

The Gauntlet requires named, fetchable, comparable references and a separate fresh-context critic. This file defines bars; it is not evidence that Grant Agent has beaten them.

## Product bar
**Grantable current nonprofit product.** Comparable on organization memory, discovery, AI writing, pipeline, team collaboration, proactive scans, and price accessibility.

To win, Grant Agent must be clearly better for the target user on at least: work actually completed, team context, explainable evidence, portal execution, portability, privacy/local option, and escalation UX - without becoming harder to understand.

## Discovery bar
**Instrumentl Discover / Pre-Award.** Compare quality/relevance of opportunities, funder evidence, deadline handling, team workflow, and time-to-shortlist.

## Deterministic research bar
**openprose/grant-finder.** Preserve source citation/provenance, freshness/status, negative evidence, deterministic retrieval, and machine-readable packets. Our wrapper must not make that layer less trustworthy.

## Computer-use bar
**Agent-S task success + our own grant-portal benchmark.** We need a repeatable benchmark for login, search, draft creation, field completion, upload, save/resume, correction, and stop-at-submit.

## Marketing-site bar
**wearecollins.com**, judged on strategic clarity, governing idea, editorial craft, distinctiveness, cultural intelligence, and system coherence - not copied visual styling. Also obey the internal Collins-Level Website Design Protocol.

## Release gates
- zero invented eligibility/deadline/award facts in test set
- official-source provenance for consequential opportunity fields
- tenant isolation tests pass
- keyboard and mobile primary journey pass
- no external submission without correct approval policy
- one complete real-world vertical slice succeeds
- rollback documented

## Loop protocol
For each slice: builder -> separate fresh critic -> blind/direct comparison -> one biggest gap -> builder. No praise requirement, no round-count exit. Stop only when ours wins the defined comparison or owner stops the loop.
