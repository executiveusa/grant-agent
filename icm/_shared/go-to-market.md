# Go-to-Market

## Sell capacity, not "AI"
The market already contains inexpensive AI grant writing and established grant databases. Grant Agent should sell **grant capacity actually removed from the team's plate**.

Core message: **A grants department that already knows your organization.**

Support: It finds opportunities, explains fit, prepares applications from verified context, coordinates your team, handles repetitive portal work, tracks obligations, and learns from every cycle.

## Initial wedge
Start with nonprofit teams that:
- pursue several grants per year
- lack dedicated full-time grant operations capacity
- have organizational knowledge scattered across people/files/apps
- lose time researching poor-fit opportunities
- repeatedly re-enter the same organizational information
- can supply real program/evidence data for a pilot

New World Kids should be the first dogfood organization before customer claims are made.

## Competitive frame
- GrantStation: affordable curated research database and education.
- Instrumentl: premium discovery/tracking/collaboration.
- Grantable: AI-native discovery/writing/pipeline and strong low-price nonprofit offering.

Grant Agent must therefore win a different category: **execution + multiplayer organizational context + portable ICM + constrained computer use + local/private option**.

## Packaging hypotheses - validate before publishing
### Core - $99/mo target
One organization. ICM brain, public-source discovery, matching, writing, tracking, core team chat.

### Operator - $299/mo target
Multiplayer team workflows, Composio integrations, proactive scans/watchdog, browser-assisted portal work, more capacity.

### Private - from $999/mo target
Local/private deployment, QVAC model/RAG option, custom retention/policy controls, deployment support. Price is a hypothesis until deployment cost and support burden are measured.

### Studio Managed - $1,500-$3,000/mo hypothesis
Software + human review/strategy/exception handling for organizations that want outcomes without operating the system themselves. Do not promise award results.

## Launch sequence
1. Dogfood with New World Kids and capture baseline labor/time/errors.
2. Run 3-5 founding nonprofit pilots with observed workflows.
3. Publish one evidence-heavy case study with measured before/after process metrics.
4. Sell through Studio packages and direct nonprofit outreach.
5. Add consultant/agency workspace only after single-org workflow is excellent.

## Distribution
- founder-led nonprofit/grant education content
- before/after workflow demonstrations
- "watch the agent do the boring part" browser videos
- partner/referral channel with fiscal sponsors, nonprofit associations, grant consultants, accountants, and capacity-building organizations
- free funding-fit diagnostic as acquisition wedge
- targeted grant calendar / opportunity brief generated from public sources

## Sales demo
Do not demo dashboards. Give the agent a real nonprofit website + uploaded docs and ask: **"What should we fund next, and what do you need from us?"** Show it build a shortlist with citations, reject weak opportunities, prepare one packet, and stop at the human gate.

## Proof required before pricing claims
Measure inference/tool cost, research recall on a known test set, false-positive fit rate, draft error rate, human review time, browser task success, and support burden.
