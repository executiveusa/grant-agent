# Prototype V1 — Submission Disabled

External grant submission is outside Prototype V1.

## Policy
- no portal login
- no browser/computer-use adapter
- no external form writes
- no terms acceptance
- no application submission
- no spend or account-setting changes

The local HTTP runtime returns HTTP 403 for POST routes containing `submit`.

Submission work begins only after QM identity/scope/policy is integrated, approval/version integrity is durable, a fresh-context evidence critic passes, and a grant-portal benchmark demonstrates safe save-draft behavior.
