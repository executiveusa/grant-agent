# 05 Submission Contract

## Reads
Approved application packet + portal policy + action authorization + credentials via secret injection.

## Does
Prefer APIs where supported. Otherwise launch isolated browser/computer-use session. Create/open application, fill only approved content, upload approved files, save/resume, verify rendered values, and capture confirmation/evidence.

## Writes
Submission trace, portal field map, screenshots/receipts where appropriate, saved-draft status, and blockers.

## Human check
Default stop is immediately before consequential Submit/attestation. Submission can be automated only if tenant policy explicitly authorizes the action class and legal/portal requirements allow it.

## Exit
Submitted confirmation or clearly recorded blocker with no ambiguous state.
