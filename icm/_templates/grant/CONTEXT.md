# Grant Record Template

Copy this folder for every pursued opportunity.

Required record fields:
- grant_id
- tenant_id
- status
- funder
- program
- official_url
- official_source_checked_at
- deadline + certainty
- amount/range + provenance
- hard eligibility
- fit analysis
- evidence gaps
- requirements checklist
- application artifacts
- approvals
- portal state
- outcome
- reporting obligations
- learning notes

The grant record links to canonical organization facts; it does not duplicate them.
