# Prototype V1 — Application Boundary

Prototype V1 stops before application drafting/submission automation becomes authoritative.

A future V1.1/V2 application slice may consume one human-selected opportunity and produce:
- official requirement checklist
- evidence map
- question inventory
- draft answer packet
- attachment checklist
- missing-fact list
- fresh-context critic result

It must not:
- invent organization facts
- silently reuse stale approved answers
- upload documents to external portals
- accept legal attestations
- submit an application

This boundary prevents the first prototype from pretending discovery/matching proof is equivalent to safe end-to-end grant submission.
