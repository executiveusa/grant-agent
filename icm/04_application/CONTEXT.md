# 04 Application Contract

## Reads
Selected opportunity + complete official guidelines/RFP + organization/program ICM + approved exemplars + budgets/evidence.

## Does
Extract every requirement into a checklist. Build response plan, attachment plan, question map, word/character limits, budget requirements, and source map. Draft from verified organization evidence. Use licensed OGrants exemplars only as analytical precedents, never as text to imitate blindly.

## Writes
Application packet: requirement checklist, draft answers, evidence citations, budget inputs, attachments manifest, unresolved questions, and critic report.

## Human check
Reviewer resolves unsupported claims, strategic choices, budgets, sensitive narratives, and required attestations.

## Exit
Fresh-context critic finds no unresolved critical requirement or invented claim.
