# Grant Agent Context

## Mode
Greenfield product built in an empty canonical repository.

## Outcome
Create a domain-specific funding operating system that reduces the human labor required to find, qualify, prepare, submit, track, report, and renew grants while preserving evidence, privacy, team context, and human accountability.

## Primary customer
Small and mid-sized nonprofit teams that need grant capacity but do not want to become grant-software operators.

## Primary action
Tell the agent what the organization needs funded. The system does the work and returns only the decisions, missing evidence, and approvals that require people.

## Governing idea
**The department that already knows.**

The interface should disappear as confidence rises. Chat is the front door; work artifacts appear only when they help a person decide, edit, approve, or take over.

## ICM form
Umbrella + pipeline + record library:
- shared nonprofit brain and policy factory
- repeatable grant lifecycle pipeline
- persistent records for organizations, funders, opportunities, applications, awards, and reports

## Non-negotiables
- ICM first; code implements explicit contracts.
- Source-cited research; no invented eligibility, deadlines, awards, or impact claims.
- Humans approve consequential submissions and external commitments.
- Least-privilege tool access; agent acts on behalf of a user/team role.
- Local/private edition is a first-class architecture, not an afterthought.
- Multiplayer context without cross-tenant leakage.
- Upstream updates from Hermes remain adoptable.
- No copied third-party code without license and architecture review.
- Website/product design follows the Collins-Level protocol: strategy before styling, proof before claims, usability before novelty.

## Definition of first verified slice
One real organization can be onboarded into ICM, one funding need can generate source-cited candidates, candidates can be ranked with explainable evidence, one opportunity can become a complete draft packet, a human can approve/reject/edit it, and the system records the result without losing provenance.
