# Prototype V1 Release Notes

## What changed
Grant Agent moved from architecture-only planning into an executable customer-zero slice.

The prototype now provides:
- New World Kids ICM instance
- plain-language funding-need intake
- Grant Finder deterministic discovery adapter
- constrained Hermes Grant Director adapter
- structured opportunity triage
- Working / Needs you / Ready state model
- durable local developer run state
- version-aware approval protection
- fail-closed missing dependency behavior
- chat-first editorial interface
- automated contract tests
- explicit no-submit invariant

## What this proves when tests/live run pass
The architecture can be exercised as a real sequence instead of remaining a conceptual diagram.

## What this does not prove
- production authentication or multiplayer isolation
- full QM runtime integration
- grant portal automation
- accuracy on all grant classes
- international/private-foundation completeness
- measured time savings
- award outcomes
- production readiness
- 9.5 Gauntlet quality
