# Prototype V1 Definition of Done

Prototype V1 is complete only when:

- automated tests pass on a clean GitHub runner;
- the local chat shell boots;
- New World Kids ICM loads;
- one real funding need produces a Grant Finder assignment;
- real Grant Finder returns source-cited candidates;
- real Hermes produces valid structured triage;
- at least one weak candidate is correctly rejected or explicitly marked review;
- missing facts create `Needs you` rather than invented answers;
- run state survives restart;
- artifact changes invalidate prior approval;
- external submission remains impossible;
- one proof record captures human/screen minutes and corrections;
- owner reviews the real output.

Anything short of those conditions is an implementation milestone, not a completed V1.
