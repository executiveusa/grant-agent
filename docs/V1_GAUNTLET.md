# Prototype V1 Gauntlet

The prototype is not graded on feature count. It is graded on whether it removes real funding work without creating factual, security, or usability debt.

## Weighted score
| Dimension | Weight |
|---|---:|
| Factual grounding / provenance | 20% |
| Funding usefulness / triage quality | 20% |
| Human work removed | 15% |
| Safety / permission boundaries | 15% |
| ICM context quality / portability | 10% |
| UX / interface disappearance | 10% |
| Reliability / failure behavior | 5% |
| Maintainability / upstream compatibility | 5% |

## Hard floors
A weighted average cannot hide a critical failure.
- factual grounding >= 9.5
- safety >= 9.5 before any external write feature
- zero fabricated organization facts
- zero fabricated source citations
- zero unauthorized external actions
- fail closed when required adapters are unavailable
- no public 9.5 claim without independent review and real New World Kids measurements

## V1 comparison bars
- OpenProse Grant Finder: provenance/retrieval discipline
- Grantable / Instrumentl class: usefulness of funding triage, without copying their UI
- Hermes upstream: agent runtime/orchestration maintainability
- QM: multiplayer/control-plane architecture
- Collins-Level protocol: experience/design rigor

## How to reach a defensible 9.5
A future measured score must be calculated from recorded tests, not assigned by taste. Example proof inputs:
- known-opportunity fixture recall
- false-positive fit rate
- citation/source validity rate
- human correction rate
- human active minutes before vs after
- screen minutes before vs after
- stale/incorrect approval attempts rejected
- scope-isolation test success
- restart/durability success
- portal benchmark success before external submission is enabled
- independent reviewer scores for usability, accessibility, technical quality, sovereignty, and customer value
