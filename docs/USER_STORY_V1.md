# Prototype V1 User Story

When New World Kids needs funding for a real program, a team member should be able to describe the need in one plain-language message and leave the repetitive discovery/triage work to Grant Agent.

The system should return only when:
- it has useful source-backed work ready, or
- a real missing fact/decision requires a human.

The user should not need to operate a grant database, construct search queries, manage subagents, or understand Hermes/QM/ICM internals to get value.

Success is fewer unnecessary research/screen minutes with no loss of factual control.
